# Tradutor

Tradutor de voz e texto que roda no navegador.

- **Voz:** reconhecimento local com Whisper (sem censura; funciona no Brave, Edge, Chrome e Firefox).
- **Texto:** tradução enquanto você digita.

## Uso local

Clique com o botão direito em `iniciar.ps1` → **Executar com o PowerShell** e abra `http://localhost:8000`.
